# 🌐 Personal Portfolio with AI Assistant

A responsive personal portfolio website built using **Python and Django** to showcase my skills, projects, education, and professional profile.

## ✨ Features

* 👤 About Me
* 💻 Skills & Technologies
* 🚀 Projects
* 🎓 Education
* 📄 Resume
* 📬 Contact Section
* 🔗 GitHub, LinkedIn & Naukri links
* 🤖 AI-Powered Portfolio Assistant

## 🛠️ Technologies Used

* Python
* Django
* HTML
* CSS
* Bootstrap
* JavaScript
* SQLite
